## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/Gauravguddeti/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 🎨 Design System

### Color Palette
- **Primary**: Modern blue gradient (#3B82F6 to #8B5CF6)
- **Background**: Dark slate gradient (#0F172A to #334155)
- **Text**: White and various grays for hierarchy
- **Accents**: Blue and purple for CTAs and highlights

### Typography
- **Primary Font**: Inter (clean, modern sans-serif)
- **Fallbacks**: Nunito, Quicksand, system fonts

### Animations
- Smooth scroll navigation
- Fade-in animations on scroll
- Hover effects with scale and glow
- Gradient text effects
- Progress bar animations

## 📱 Responsive Design

The website is fully responsive with:
